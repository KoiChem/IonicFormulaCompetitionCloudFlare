# 通常版との照合（2026-10-10）

通常版の `tests/cloudflare/browser-server.ts` を独立DBで起動し、教員の作成・管理設定・難易度、QR待機、生徒の参加・待機、まとめて判定の解答と確認、ホストの全画面レース、中断ダイアログ、両者の結果画面を実操作で確認した。通常版の本番Worker・DBは変更していない。

| 画面 | 修正の基準 |
| --- | --- |
| ホーム | 通常版のホーム構造、参加状況・復帰リンク、JoinCodeForm。メイトマッチは合意どおりdisabled |
| 作成 | CompetitionSettingsFormを直接使用。判定方式2択、説明、間隔、ReturnHomeButtonを維持 |
| 管理設定・難易度 | 通常版の切替ヘッダーと難易度カード、ダイアログの全描画。今回のGoogle認証依頼に合わせ許可教員管理はマスターのみ有効化。メイトのカードとメイト本体はdisabledのまま |
| 参加・待機 | JOIN、1〜16文字、設定と人数、個人情報の注意、NicknameEditorと同じ表示 |
| ホスト待機 | Lobbyを直接使用、参加者除外、EndRoomButton、設定変更のdetails |
| ホスト競技 | RoomScreen/ClassRunningと同じmainとHostRace、時刻・進捗・提出・モーション操作・中断 |
| 解答 | CompetitionPlayerV2の描画構造、既存キーボード・タブ・正誤表示・一覧を使用 |
| まとめて判定 | 入力済み欄数、前/次/全解答確認、DeferredReviewQuestion、提出後変更不可 |
| 結果・復習 | 通常版Resultsを直接使用。生徒上位3位は2026-10-10に明示承認済み |
| 履歴 | 通常版と同じ分類、文言、設定・成績・期限・再確認 |

描画以外はLiteのRoom単位のSQLiteとWebSocketで処理する。GoogleのJWT検証helperだけを再利用し、通常版のAuth保存領域、D1、過去の実施データは持ち込まない。

確認範囲：ホーム・作成画面の座標・寸法・フォント・余白を通常版と320/390/768/1280pxで比較し、一致を確認。管理カード・難易度・式/名称入力・結果画面に横はみ出しなし。通常版とLiteの生成CSSは同一。問題毎判定とまとめて判定の25/50人同時操作、51人目拒否、重複得点防止を検証。実機・学校回線での速度は別途実地確認が必要。
