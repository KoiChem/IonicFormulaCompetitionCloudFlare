# GitHub版の錯イオンと難易度管理

錯イオン17件・錯塩36件を収録。標準10イオン・4錯塩は初期有効、発展項目は初期無効です。マスター教員は管理設定の「難易度調整」で各項目をやさしめ／ややむず／両方／出題しないに設定できます。教材の根拠は [根拠台帳](COMPLEX_IONS_EVIDENCE.md) を参照してください。

部屋の「錯イオン OFF／ON」は初期OFF。ONでは保存済みのモード別・難易度別割合に従って錯イオン問題を確保し、カテゴリ重みと項目設定に従って重複なく選びます。新しい部屋には作成時の出題設定を固定保存し、その後の管理設定変更は既存の部屋に影響しません。設定を持たない旧部屋には従来の生成処理を適用します。

管理画面は「クラスコンペ」と「管理設定」に分け、許可教員、メイトコンペの公開、難易度調整をまとめています。難易度の保存はリビジョン照合とリクエストIDで競合・再送を処理します。Supabaseには専用の追加テーブルを作り、ブラウザから直接読み書きできない権限を設定しています。

式キーボードはシフトで文字ケースと丸／角括弧を切り替え、括弧キーの上下フリックで反対の括弧を入力します。電荷4−も追加しています。やさしめ・錯イオンONの名称解答には8個の名称補助を表示します。Google認証、private Realtime、サーバー時刻との同期を維持しています。

## 移行・検証

元版の保存済み設定（revision5、イオン22項目・化合物80項目の指定、割合30/35/20/40％）を完全取得し、GitHub版の独立したrevision1として登録しました。元版との自動同期はありません。

自動テスト454件、PostgreSQLの権限・競合・部屋設定固定、出題24通り、ローカルブラウザの保存・検索・画面幅を確認しています。公開後の検証記録は [作業台帳](COMPLEX_PORT_PROGRESS.md) を参照してください。実機のタッチと教室の同時利用は別の受入確認です。
